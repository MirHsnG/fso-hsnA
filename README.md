# Full Stack Open

My solutions and exercises for the **Full Stack Open** course by the **University of Helsinki**.

## Repository Structure

The exercises are organized by course part:

```text
fso-hsnA/
├── fso-hsnA-0/
├── fso-hsnA-1/
├── fso-hsnA-2/
└── ...
```

Each part contains the exercises and projects completed for that section of the course.
